# Security

ข้อมูลนักเรียนเป็นข้อมูลส่วนบุคคล แอปใช้ Supabase Auth และ RLS โดยเปิดสิทธิ์เฉพาะผู้ใช้ที่ authenticated

อย่าเพิ่ม service role key หรือ secret key ลงใน frontend, GitHub หรือไฟล์สาธารณะ

ก่อนเปิดใช้งานจริง ควรสร้างบัญชีผู้ใช้งานเฉพาะเจ้าหน้าที่ที่มีหน้าที่เกี่ยวข้อง และทบทวนสิทธิ์แก้ไข/ลบข้อมูลตามนโยบายของหน่วยงาน
